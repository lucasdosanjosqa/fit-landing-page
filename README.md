# Fit Landing Page

A clean, responsive landing page for a fictional fitness app. The project presents the app's core experience—from nutrition tracking and workout logging to sharing progress with friends—through a focused, mobile-first interface.

## Highlights

- Responsive, mobile-first layout
- Semantic HTML structure
- Accessible labels, alternative text, and keyboard focus states
- Fitness app screenshots presented in alternating feature sections
- Clear call-to-action section
- Smooth in-page navigation
- Lightweight implementation with no JavaScript or external frameworks

## Built With

- HTML5
- CSS3
- [Google Fonts](https://fonts.google.com/specimen/Roboto) — Roboto

## Getting Started

No installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/fit-landing-page.git
   ```

2. Open the project directory:

   ```bash
   cd fit-landing-page
   ```

3. Open `index.html` in your browser.

For a development server with automatic reload, you can also use an editor extension such as Live Server.

## Responsive Design

The base styles target smaller screens first. At `761px` and above, the layout expands into a desktop presentation with:

- A three-column hero section
- Alternating image-and-text feature rows
- A compact, centered call-to-action panel

## Page Sections

1. **Header** — Brand mark and download link
2. **Hero** — Main message, app preview, and product highlights
3. **Features** — Nutrition tracking, exercise logging, and social sharing
4. **Call to Action** — Download prompt with free-access messaging
5. **Footer** — Copyright notice

## Deploying with GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** under **Code and automation**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will display the public URL after the deployment finishes.
